# alu-back-end

Back-end projects for ALU.

## api

Scripts that gather data from a REST API (https://jsonplaceholder.typicode.com).

- `0-gather_data_from_an_API.py`: takes an employee ID as an argument and prints that employee's TODO list progress.

Usage:

    python3 api/0-gather_data_from_an_API.py 2
